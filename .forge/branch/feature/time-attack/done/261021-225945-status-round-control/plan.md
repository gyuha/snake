# status.html에서 시간제한 라운드 시작·종료 컨트롤

## 목표 / 비목표
- 목표: `status.html`에서 분(정수 1~60, 기본 10)을 입력하고 시작을 누르면 서버가 월드를 리셋하고 해당 시간 동안 라운드를 진행한다. 남은 시간은 카운트다운으로 보이고, 00:00이 되면 월드가 정지하며 화면 가운데에 큰 `00:00`이 뜬다. 플레이어 화면(`index.html`)에도 남은 시간과 종료 오버레이를 보여 준다.
- 비목표:
  - 컨트롤 접근 제한(토큰·인증). 공개 URL이라 관전자 누구나 시작·재시작할 수 있다. 이 결정은 의도된 것이다.
  - 중단 버튼, 일시정지.
  - 소수 분 입력, 60분 초과.
  - 라운드 이력·기록 저장.
  - 서버 기동 직후의 동작 변경(라운드 시작 전에는 지금처럼 상시 진행하며 타이머를 표시하지 않는다).

## 확정된 동작 (그릴링 결정)
- **라운드 상태**: 없음(서버 기동 직후, 상시 진행) → 진행 중 → 종료(정지). 진행 중·종료 어느 상태에서든 시작을 누르면 새 라운드가 시작된다.
- **시작(리셋)**: 플레이어 뱀을 모두 사망 처리하고(소켓 유지, 기존 사망 화면으로 복귀해 재참가), 봇은 새로 스폰하며, 점수와 먹이를 초기화한다.
- **종료**: 월드 틱과 봇이 멈춘다. 신규 `join`은 거부한다. 종료 후에도 순위·점수는 마지막 값으로 고정된다.
- **시간 기준**: 서버가 종료 시각을 정하고 남은 시간을 알린다. 클라이언트는 알려 준 남은 시간에서 로컬로 카운트다운한다. 접속 직후(새로고침 포함) 현재 라운드 상태를 받아 타이머가 이어진다.
- **시작 명령**: `status.html`의 관전 소켓이 새 메시지(`startRound{minutes}`)를 보낸다. 서버는 정수 1~60 범위 밖이면 무시한다.
- **status.html 화면(시안 확정)**: 진행 중에는 맵 위 가운데 상단에 큰 카운트다운, 컨트롤(분 입력 + 시작)은 오른쪽 패널 상단. 종료 시에는 정지된 맵 위에 어두운 막을 깔고 가운데에 큰 `00:00`, 그 아래 "게임 종료", 그 아래 "1위 이름 · 점수" 한 줄. 오른쪽 패널의 순위는 최종 점수로 남는다.
- **플레이어 화면**: HUD에 남은 시간을 작게 표시하고, 종료 시 "게임 종료" 오버레이를 띄운다.

- 용어: `.forge/CONTEXT.md`의 **라운드**, **종료 상태**

  1. `npm test`가 통과하고 새 테스트가 포함된다. 기준선: 20개 파일 179개 테스트 통과(작업 전). 회귀 가드이므로 이미 통과 상태가 맞다.

  3. 새 테스트가 구현 전에 실패했고(red) 구현 후 통과한다(green): 프로토콜 `startRound`/라운드 상태 메시지 왕복, 서버 라운드 상태 전이(없음 → 진행 중 → 종료, 재시작), 분 범위 밖 요청 무시, 시작 시 플레이어 뱀 사망·점수 초기화, 종료 후 월드 정지와 `join` 거부, 새 관전자 접속 시 현재 라운드 상태 수신.
  4. `status.html`에 필요한 요소(분 입력, 시작 버튼, 타이머, 종료 오버레이) 존재를 `packages/client/test/status-html.test.ts`가 확인한다. 타이머 표시용 순수 함수(남은 ms → `MM:SS`)는 단위 테스트로 검증한다.
  5. 수동 검증: `npm run dev`로 띄우고 Playwright로 `/status.html`에서 1분을 입력하고 시작해 카운트다운과 종료 화면(큰 `00:00` + 1위 한 줄) 스크린샷을 확인한다. 게임 탭 하나를 열어 두고 시작 시 사망 화면으로 돌아가며 종료 시 오버레이가 뜨는지 확인한다.
  - 클라이언트 쪽 `spectate` 사용처 finder: `git grep -n "'spectate'\|SPECTATE" -- packages scripts ':!*.md'` (작성 시점 실행 결과: client 1곳, server 1곳, 테스트 3개 파일, protocol 정의 부분). 새 메시지는 같은 지점들에 대응해 추가한다.
  - 이 작업은 오류 수정이 아닌 신규 기능이므로 fix-forward eval 규칙 대상이 아니다.
