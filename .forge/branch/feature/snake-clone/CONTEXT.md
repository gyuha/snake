# Snake

멀티플레이 스네이크 게임. 플레이어는 시작 화면에서 자기 뱀의 겉모습을 고른다.

## 겉모습 (Appearance)

**스킨 (Skin)**:
뱀의 몸통 색상 조합(몸통색 + 줄무늬색). 8종이며 와이어의 `skin` 값이다.
_Avoid_: 색상 세트, 컬러

**동물 (Animal)**:
뱀의 머리와 꼬리 모양을 정하는 선택 축. 스킨과 독립이며 몸통에는 영향을 주지 않는다. 기본, 강아지, 고양이, 뱀, 팬더, 토끼의 6종이다.
_Avoid_: 캐릭터, 테마, 스킨 (스킨은 색상만 뜻한다)

**기본 (Default animal)**:
동물 목록의 첫 항목으로, 동물 스킨 도입 이전의 머리(눈 두 개)와 둥근 꼬리 끝 모양이다.
_Avoid_: 없음, 노멀
